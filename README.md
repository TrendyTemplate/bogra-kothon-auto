# বগুড়া কথন নিউজ অটোমেশন - সহজ সেটআপ গাইড

## ধাপ ১: ফাইলগুলো ডাউনলোড করো
`bogra_kothon_automation` ফোল্ডারটা তোমার কম্পিউটারে নিয়ে যাও।

## ধাপ ২: Python ইনস্টল করো
- https://www.python.org/downloads/ থেকে Python 3.10+ ডাউনলোড করো
- ইনস্টলের সময় **"Add Python to PATH"** টিক মার্ক দাও

## ধাপ ৩: লাইব্রেরি ইনস্টল করো
কমান্ড প্রম্পট/টার্মিনাল খুলে ফোল্ডারে যাও এবং লিখো:
```
pip install -r requirements.txt
```

## ধাপ ৪: লোগো বসাও
`logo.png` নামে তোমার লোগোটা একই ফোল্ডারে রাখো।

## ধাপ ৫: ফেসবুক সেটআপ (একবারই করতে হবে)
আমি আলাদা করে সহজ গাইড দিব।

## চালানো
```
python main.py
```
